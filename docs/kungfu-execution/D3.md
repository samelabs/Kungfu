## Required（↔ 条款）

1. `thread_entries(id, thread_id, seq, author_id, memory_id, memory_revision, reply_to_id?, asked[], assign_id?)`：`seq` 取 `threads.next_seq` 同事务原子递增；条目不可改不可删。
2. `thread_post(thread, content|memory, summary?, reply_to?, ask?)`：
   - 锁 thread 行（与 join/close/key 串行化，L5），仅开放房 + 有发言权 + 活跃成员；
   - `content`：同事务创建 `origin='thread'` 记忆（title 空、description=summary、凭据扫描沿用现有 standalone 检查、不走 standalone 消费路径），固定其 revision=1；`memory=code`：本人有效记忆或他人有效公开记忆的**当前版本**，固定 revision；越权引用拒（§5/§9）；
   - `summary` ≤500 字，内容 >500 字必填（`SUMMARY_REQUIRED`→revise）；
   - `reply_to` 仅本线程已有条目；`ask` ⊆ 有发言权成员 − 本人（R-15），≤50（`INVALID_TARGET`→retry）；
   - **回应对象四规则**按序唯一计算（明示致含空集→回复作者〔无发言权则空不回退〕→恰两发言方→周知），`asked` 按发言时刻冻结写库；返回 `asked`；
   - 回复 p 同事务 CAS 了结本人对 p 的 pending（resolution=reply）；无 pending 回复也合法。
3. `thread_receipts(id, thread_id, entry_id, account_id, state∈{pending,fulfilled,withdrawn}, resolution?, note?, resolved_at?)`：PK 唯一 (entry,account)；产生=同事务随条目 INSERT；`fulfilled→resolution∈{reply,handle,take}`（take 值 D4 才写入，枚举列现在就建全）；`withdrawn→resolution∈{retract,leave,remove,role_change,close}`；`note` 仅 handle。
4. `thread_handle(thread, entry, note?)`：承担者 CAS pending→fulfilled/handle，note ≤1KB 持久；非承担者/无 pending → 无效果拒绝（`INVALID_TARGET`）。
5. `thread_retract(thread, entry)`：条目作者且仍为成员；该条目全部 pending → withdrawn/retract；已发生履行不可撤销（只动 pending）。
6. **收束钩子**（替换 D2 占位，全部同事务）：leave/remove → withdrawn/{leave,remove}；set_role 降级 → withdrawn/role_change；close → withdrawn/close（§6.5：连同 D4 分派处置，本阶段只接收据）。
7. `thread_get` 填时间线（seq/作者/summary/reply_to/asked/携带分派标记，≤50/页 keyset cursor on seq）与本人未了事项；`entries=[…]` 展开载荷记忆全文与 revision。
8. 幂等：post/handle/retract 走 `runThreadAction`；快照只含协议事实字段（entry seq、memory、revision、asked、产生的回执、了结的回执），不含成员数/时间线等投影（A6 的 post 版）。
9. thread 记忆固定引用撤回后：时间线条目仍显示、载荷返回「当前不可读」，不泄正文（§5）。

## 负测（必须）

- A2 四规则各一例 + 致本人拒 + 后加入者不扩大 asked；A3 回复即了结/无 pending 回复；A4 handle note 持久、retract 只动 pending、非成员 retract 拒
- 已关闭房 post/handle/retract 拒（THREAD_CLOSED→stop）；旁观者 post 拒
- 引用他人私有记忆拒；引用已撤回记忆拒；撤回后载荷不可读不泄正文
- 并发：同 (entry,account) 回执只一行；reply 与 handle 并发恰一次了结（A17）；并发 post seq 严格递增不重
- 幂等：post 后改 subject/后续发言，重放返回首次快照；同 key 异请求冲突零副作用；handle 重放不重复了结
- 收束四路径后：该成员 pending 清零、resolution 各自正确；重新加入不复活
- 内容 >500 字无 summary 拒（revise）
