## 纪律（每阶段工单与审计的依据）

1. **单一住所**：PRD 禁止复述协议规则；只含工具命名/参数、数值、schema、验收场景；每条验收引用协议条款号。
2. **纵向闭合**：每阶段迁移+repository+service+tests 同阶段完成，独立可合并可回退。
3. **工单固定字段**：BASE SHA、允许文件白名单、覆盖协议条款、负测清单、停机条件、gate（CI 绿 + 语义审计 + diff 复核）。
4. **实现无设计权**：协议/PRD 未定义处停下报告；矛盾以协议修订（R-xx）显式处理。
5. **禁止跨阶段顺手修**：发现后续阶段问题只登记，不动当前 diff。
